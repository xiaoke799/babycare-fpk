# 育儿宝 (BabyCare-FPK) - 飞牛 fnOS 原生育儿应用

**语言 / Language**: [简体中文](README.md) | [English](README_EN.md)

## 简介

育儿宝是飞牛 fnOS 平台原生 NAS 育儿应用，面向使用飞牛 OS NAS 的家庭用户，主打本地私有存储，所有育儿相关数据全部保存在用户自己的 NAS 设备内，不上传第三方云端，契合当下用户对个人家庭隐私安全的诉求，打造属于家庭的私密育儿数字空间。

## 核心功能

### 📊 成长记录
- 身高、体重、头围记录，生成 WHO 生长曲线（百分位）
- BMI 自动计算、生长速度追踪、记录关联分析
- 成长对比照片管理
- **宝宝时间线**：全部记录按类型 / 时段筛选回溯
- 阶段报告：睡眠 / 喂养 / 排泄 / 成长四类分析
- **周报 / 月报**：本周（本月）关键指标 + 与上一周期环比
- 年度成长报告（含 AI 年度总结）
- **看诊摘要可打印 / 另存 PDF**，把最近体温、用药、过敏、疫苗打成一张纸带去门诊

### 🍼 照护追踪
- 喂奶记录（母乳、配方奶、辅食分类，含奶量和哺乳侧）
- 睡眠记录（时段、质量、自动统计）
- 换尿布记录（小便/大便/混合）
- 吸奶记录、趴睡训练记录

### 🏥 健康档案
- 体检记录、体温监测、用药记录
- 疫苗管理：接种计划、厂家 / 批号 / 剂次、不良反应、抗体结果
- 过敏测试、辅食过敏史、囟门检查、出牙记录
- 检验指标（名称 / 数值 / 参考区间 / 异常标记）
- 视听力筛查结果与转诊记录
- **健康随访规划**：常规 12 档 + 早产 6 档预约卡，到点提醒，
  完成体检后自动对账（不拖体检）
- **提醒推送**：喂奶 / 尿布 / 用药 / 疫苗 / 体检与自定义健康提醒
  （微信 · 钉钉 · 飞书 · Bark · PushPlus，支持勿扰时段）
  ⚠️ 用药与体检提醒以「提醒」配置为准；`medication_records` 表上的
  `next_dose_time` 只是历史残留字段，不参与调度

### 🎯 发育评估
- 成长里程碑记录（可标记「第一次」）
- 发育里程碑明细（编码 / 预期月龄 / 状态）
- ASQ 发育筛查**结果登记**（五维得分 + 结论）
  ⚠️ 应用内**不含 ASQ 题目与评分算法**——ASQ 问卷需向官方购买，
  在此按问卷结果登记五维得分与结论（normal / monitor / refer），不做自动评分
- 发育飞跃期追踪（1~10 次）

### ✍️ 育儿日记
- 记录宝宝成长瞬间，支持 Markdown 简单排版与图文混排
- 上传对比照片（照片可内联到日记正文里）
- AI 辅助生成日记内容
- **那年今日**：往年同月同日发生过什么（喂养 / 睡眠 / 里程碑 / 照片全都能命中）
- **全局搜索**：跨日记、喂养、健康档案等十余类数据查一句话

### 🤖 AI 辅助育儿
- 成长记录智能总结
- 育儿建议
- 照片内容描述
- 日记生成
- 问题答疑
- **AI 帮写**：一句话记录 / 日记帮写 / 本周总结 / 里程碑建议等
  11 类场景，说一句话自动整理成规范记录
- **小萌对话内直接记录**：在小萌浮窗对话框里直接说话就能记
  （如「刚喝了 120ml 奶」），AI 自动识别类型并提取字段，弹出确认卡，
  点「记下来」才写入；设置 → AI 大模型里有授权开关，默认开启

### 📚 育儿知识库
- 内置喂养、睡眠、发育、健康、护理等方面知识文章
- 辅食食谱推荐（难度 / 营养 / 制作要点）
- 亲子活动库（室内外 / 季节 / 时长），支持收藏与完成记录
- **本月育儿要点**：按月龄下发（发育特点 · 疫苗 · 能玩 · 能吃 ·
  常见疑问 · 安全排查 · 预警信号 · 急救），只提示不判读，
  用药剂量一律不写

### ⏱️ 工具
- 喂奶计时器、睡眠计时器（停止时可自动生成记录）
- 安抚音效（本地合成，不依赖外部音频文件）
- **家庭成员与记录者**：记录「这条是谁记的」，回看时一目了然
- **今日奶量目标**：按日龄与体重自动估算，也支持按医生方案
  自定义（30-3000ml），达成情况一眼可见
- **自定义倒计时**：把「还有多少天」挂在首页（随访、预产期等）
- 纸尿裤比价记账（多品类比价 + 支出记录）
- 数据导出：单宝宝 JSON、全量 JSON、疫苗 CSV
- 含相册的 ZIP 备份与恢复、导出到 / 从 fnOS 共享目录恢复
  ⚠️ 「导入」指恢复本应用自己生成的备份包，**不支持通用格式导入**
- 删除安全码：删宝宝 / 恢复备份前必须验证，防误删
- 集成 API Token（用于 Home Assistant 等外部集成）
- **入站 Webhook**：给床头无线按钮 / 手机自动化脚本一条
  「一句话记一笔」的通道（喂养 / 尿布 / 睡眠 / 体温四类事件）。
  独立 Token，可单独吊销，不影响集成 Token；带字段白名单、数值范围钳制、
  限流与调用审计。仅局域网可达（音箱类云端助手访问不到局域网地址）

### 🏠 智能家居
- 内置 Home Assistant 集成（`ha-integration/`）：传感器、服务、计时开关
- 一个宝宝 = 一个设备，实体挂在对应宝宝设备下
- **快捷记录按钮**：记亲喂 / 记换尿布，按一下写一条记录
  （适合仪表盘卡片、NFC 贴纸、语音助手）
- **今日换尿布次数**传感器
- Token 失效时 HA 弹窗重新认证，**不用删掉集成重加**（实体 ID 不变）
- 集成 Token 只能读数据 + 写记录类，**不能**改设置、删宝宝或动备份
- Token 鉴权，数据仍留在本地 NAS

## AI 功能说明

育儿宝支持接入大模型 LLM 能力，提供两种使用模式：

### 1. 联网 API 模式
调用外部在线大模型接口（如 DeepSeek、Kimi、OpenAI 等）。

⚠️ **隐私风险提示**：选择第三方联网 API 服务时，宝宝照片、成长日记、喂养记录等育儿数据会传输到对应第三方大模型服务商服务器。数据会离开您的 NAS 本地存储环境，建议处理高度敏感信息时谨慎使用。

### 2. 本地部署大模型模式（推荐，隐私优先）
大模型运行在 NAS 本机硬件，所有 AI 推理计算全部在本地完成。宝宝数据不会离开您的 NAS 设备，完整保留本地隐私优势。

详见 [隐私政策](PRIVACY.md) 和 [用户协议](USER_AGREEMENT.md)。

## 技术架构

- **后端**：Python Flask + Gunicorn + SQLite
- **前端**：原生 HTML/CSS/JavaScript（响应式设计）
- **访问方式**：飞牛 OS 网关（Unix Socket）
- **数据存储**：SQLite 数据库 + 飞牛 fnOS 数据目录
- **AI 接入**：支持 OpenAI 兼容 API 和本地 Ollama

## 本地开发

```bash
cd app/backend
pip install -r requirements.txt
python3 server.py    # 默认 http://localhost:8090，可用环境变量 BABYCARE_PORT 覆盖
```

本地开发模式默认关闭无口令登录，需设置环境变量 `BABYCARE_DEV_AUTH=1`
后调用 `POST /api/auth/login` 登录；fnOS 生产环境由网关认证，无需此开关。

## 打包发布

```bash
fnpack build -d babycare-fpk
# 生成 babycare-fpk.fpk
```

注意：在 Windows 上打包后，需将包内生命周期脚本的执行位修复为 0755
（Windows 文件系统不保留 Unix 执行位），否则脚本在 fnOS 设备上无法运行。
